FriESP — ESP32 Reactive Face 🤖

An animated electronic face developed with the ESP32-S3 and MicroPython.

FriESP is an embedded systems project that aims to turn an ESP32-S3 into a small electronic character with animated facial expressions and dynamic reactions to temperature and movement.

The project combines display graphics, sensor integration, and MicroPython programming to create a simple interactive character.

✨ Features

Animated facial expressions.

Blinking eyes and dynamic facial movements.

Temperature-based expressions, such as feeling hot or cold.

Motion and rotation detection to simulate dizziness.

Modular code structure for easier maintenance and future improvements.

🛠️ Hardware and Technologies

Microcontroller: ESP32-S3

Programming language: MicroPython

Display: TFT display with ST7789 controller

Motion sensor: Accelerometer and gyroscope, subject to hardware verification

Temperature sensor: Temperature and pressure sensor, subject to hardware verification

🚧 Development Status

The project is currently under development.

Initial display test completed.

Basic facial design.

Temperature sensor integration.

🎯 Goals

The main goal is to explore embedded systems, sensor integration, graphical rendering, and interactive behavior on a microcontroller.

This project is being developed incrementally, with physical hardware testing and assistance from AI tools during implementation and debugging.
