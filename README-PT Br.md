FriESP — Rosto Eletrônico Reativo 🤖

Um rosto eletrônico animado desenvolvido com ESP32-S3 e MicroPython.

O FriESP é um projeto de sistemas embarcados que busca transformar um ESP32-S3 em um pequeno personagem eletrônico com expressões faciais animadas e reações dinâmicas à temperatura e aos movimentos.

O projeto combina gráficos em tela, integração de sensores e programação em MicroPython para criar um personagem interativo.

✨ Funcionalidades

Expressões faciais animadas.

Olhos piscando e movimentos faciais dinâmicos.

Expressões baseadas na temperatura, como sentir frio ou calor.

Detecção de movimentos e rotações para simular tontura.

Código modular para facilitar a manutenção e futuras melhorias.

🛠️ Hardware e Tecnologias

Microcontrolador: ESP32-S3

Linguagem de programação: MicroPython

Tela: Display TFT com controlador ST7789

Sensor de movimento: Acelerômetro e giroscópio, sujeitos à confirmação do hardware

Sensor de temperatura: Sensor de temperatura e pressão, sujeito à confirmação do hardware

Implementação das animações faciais.

🎯 Objetivos

O principal objetivo é explorar sistemas embarcados, integração de sensores, renderização gráfica e comportamentos interativos em um microcontrolador.

O projeto está sendo desenvolvido por etapas, com testes no hardware físico e auxílio de ferramentas de inteligência artificial durante a implementação e a depuração.

📌 Observação

Este é um projeto experimental e educacional, desenvolvido para aprendizado e exploração de sistemas embarcados.
